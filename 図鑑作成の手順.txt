図鑑作成の手順

 基本的には、2つの場所にあるファイルを編集するだけ。
   * データ: src/data/birds.json
   * 画像: public/images/

この内容で ZUKAN_MANUAL.md を作成します。

 │     24 ### 手順1-1: `birds.json` に鳥のデータを追加する                                           │
 │     25                                                                                            │
 │     26 1.  `src/data/birds.json` ファイルを開きます。                                             │
 │     27 2.  既存の鳥のデータブロック（`{` から `}` まで）をどれか一つ、丸ごとコピーします。        │
 │     28 3.  コピーしたブロックを、リストの最後（最後の `}` の手前）に貼り付けます。                │
 │        **この時、直前の `}` の後ろにカンマ `,` を必ず追加してください。**                         │
 │     29 4.  貼り付けたブロックの内容を、新しい鳥の情報に書き換えます。                             │
 │     30                                                                                            │
 │     31 **【重要】 各項目の意味**                                                                  │
 │     32 - `id`: **（必須）** 他の鳥と重複しない、ユニークな**半角英数字**                          │
 │        のID。これがページのURLになります。（例: `"shimaenaga"`）                                  │
 │     33 - `name`: 鳥の和名。（例: `"シマエナガ"`）                                                 │
 │     34 - `scientificName`: 鳥の学名。（例: `"Aegithalos caudatus"`）                              │
 │     35 - `category`:                                                                              │
 │        カテゴリー名。既存のカテゴリーに合わせるか、新しいカテゴリー名を付けられます。             │
 │     36 - `description`: 図鑑の標準ページで表示される、鳥の簡単な説明文。                          │
 │     37 - `mainImage`: 一覧ページや詳細ページのメインで表示される画像のパス。                      │
 │        `/images/【idと同じ名前】/main.jpg` のようにするのがおすすめです。                         │
 │     38 - `galleryImages`: 詳細ページ下部のギャラリーに表示される画像のリスト。                    │
 │     39                                                                                            │
